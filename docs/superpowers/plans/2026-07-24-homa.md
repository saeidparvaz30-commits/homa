# Homa Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Homa — a featherweight Windows system-tray app that watches `~/.claude/sessions/*.json`, classifies each Claude Code agent as Working / Idle / Waiting / Ended, and signals attention via tray icon, toasts, an optional sound, and an always-on-top mini-pill overlay.

**Architecture:** A Tauri 2 app. The Rust core polls the sessions directory (file-watch + reconcile), checks pid liveness, maps raw status into Homa's state model, lazily enriches from transcript JSONL when the window is open, aggregates a tray summary, detects state transitions, and drives the tray/toasts/overlay. The React/Tailwind frontend renders a roster view and a tamagotchi view, plus the overlay window, from `AgentState[]` pushed over Tauri events.

**Tech Stack:** Tauri 2, Rust (serde, serde_json, notify, sysinfo, tauri plugins: notification, autostart, positioner, single-instance), React 18 + TypeScript + Vite + Tailwind, Vitest + Testing Library.

## Global Constraints

- **Platform:** Windows 11. All paths, process checks, and hooks must work on Windows. Dev shell is PowerShell or Git Bash.
- **Footprint:** Must stay featherweight (Tauri/WebView2, no Electron). Transcript enrichment runs ONLY while the main window is visible.
- **Substrate:** Read-only consumption of `~/.claude/sessions/<pid>.json` and `~/.claude/projects/<slug>/<sessionId>.jsonl`. Never write into `~/.claude`.
- **State model:** Only `Working` is calm. `Idle` and `Waiting` are both attention states, visually distinct. Priority for the tray: `Waiting` (3) > `Idle` (2) > `Working` (1) > `Ended` (0).
- **Status mapping:** `busy`→Working, `idle`→Idle. Any string in the configurable `WAITING_STATUSES` set →Waiting. Any other non-empty unknown value → Idle (fail toward attention, never hidden).
- **Context window constant:** `CONTEXT_WINDOW_TOKENS = 200_000.0` for context-% math (single constant, easy to revisit).
- **Copy rule:** No em dashes in any user-facing string. No `Co-Authored-By` trailers in commits.
- **Sessions dir resolution:** `dirs::home_dir()` joined with `.claude/sessions`. Overridable via env `HOMA_SESSIONS_DIR` (used by replay/fixture mode).

```rust
use crate::model::AgentStatus;

pub const WAITING_STATUSES: &[&str] = &["waiting", "waiting_for_input", "needs_input", "input", "blocked"];

pub fn map_status(raw: &str, pid_alive: bool) -> AgentStatus {
    if !pid_alive { return AgentStatus::Ended; }
    let r = raw.trim().to_ascii_lowercase();
    if r == "busy" { return AgentStatus::Working; }
    if r == "idle" { return AgentStatus::Idle; }
    if WAITING_STATUSES.contains(&r.as_str()) { return AgentStatus::Waiting; }
    AgentStatus::Idle // unknown non-empty: fail toward attention
}
```

```rust
use serde_json::Value;

pub const CONTEXT_WINDOW_TOKENS: f32 = 200_000.0;

#[derive(Debug, Default, Clone, PartialEq)]
pub struct Enrichment {
    pub model: Option<String>,
    pub context_pct: Option<f32>,
    pub branch: Option<String>,
    pub last_activity: Option<i64>,
}

pub fn enrich_from_lines(lines: &[String]) -> Enrichment {
    let mut out = Enrichment::default();
    for line in lines.iter().rev() {
        let v: Value = match serde_json::from_str(line) { Ok(v) => v, Err(_) => continue };
        if out.branch.is_none() {
            if let Some(b) = v.get("gitBranch").and_then(|b| b.as_str()) {
                if !b.is_empty() { out.branch = Some(b.to_string()); }
            }
        }
        if v.get("type").and_then(|t| t.as_str()) == Some("assistant") {
            let m = &v["message"];
            out.model = m.get("model").and_then(|x| x.as_str()).map(String::from);
            if let Some(u) = m.get("usage") {
                let g = |k: &str| u.get(k).and_then(|x| x.as_f64()).unwrap_or(0.0) as f32;
                let used = g("input_tokens") + g("cache_read_input_tokens") + g("cache_creation_input_tokens");
                out.context_pct = Some((used / CONTEXT_WINDOW_TOKENS * 100.0).clamp(0.0, 100.0));
            }
            return out; // latest assistant turn is authoritative
        }
    }
    out
}
```

```rust
use crate::model::{AgentState, AgentStatus};

#[derive(Debug, PartialEq, serde::Serialize)]
pub struct TraySummary { pub top: AgentStatus, pub waiting: usize, pub idle: usize, pub working: usize }

pub fn summarize(agents: &[AgentState]) -> TraySummary {
    let mut top = AgentStatus::Ended;
    let (mut waiting, mut idle, mut working) = (0, 0, 0);
    for a in agents {
        if a.status.priority() > top.priority() { top = a.status; }
        match a.status {
            AgentStatus::Waiting => waiting += 1,
            AgentStatus::Idle => idle += 1,
            AgentStatus::Working => working += 1,
            AgentStatus::Ended => {}
        }
    }
    TraySummary { top, waiting, idle, working }
}

#[derive(Debug, PartialEq, Clone, serde::Serialize)]
pub struct Transition { pub session_id: String, pub name: String, pub to: AgentStatus }

pub fn transitions(prev: &[AgentState], next: &[AgentState]) -> Vec<Transition> {
    let mut out = Vec::new();
    for n in next {
        if !matches!(n.status, AgentStatus::Waiting | AgentStatus::Idle) { continue; }
        let old = prev.iter().find(|p| p.session_id == n.session_id);
        let changed = match old { Some(p) => p.status != n.status, None => true };
        if changed {
            out.push(Transition { session_id: n.session_id.clone(), name: n.name.clone(), to: n.status });
        }
    }
    out
}
```

```rust
// poller.rs
use std::path::{Path, PathBuf};
use sysinfo::System;
use crate::{session::parse_session, mapper::map_status, derive::repo_from_cwd,
    enrich::enrich_from_path, liveness::pid_alive, model::AgentState};

pub fn sessions_dir() -> PathBuf {
    if let Ok(p) = std::env::var("HOMA_SESSIONS_DIR") { return PathBuf::from(p); }
    dirs::home_dir().unwrap_or_default().join(".claude").join("sessions")
}

fn transcript_path(cwd: &str, session_id: &str) -> PathBuf {
    let slug = cwd.replace(['\\', '/', ':'], "-").replace(' ', "-");
    dirs::home_dir().unwrap_or_default().join(".claude").join("projects").join(slug)
        .join(format!("{session_id}.jsonl"))
}

pub fn scan_once(dir: &Path, enrich: bool) -> Vec<AgentState> {
    let mut sys = System::new();
    sys.refresh_processes();
    let mut out = Vec::new();
    let entries = match std::fs::read_dir(dir) { Ok(e) => e, Err(_) => return out };
    for entry in entries.flatten() {
        let path = entry.path();
        if path.extension().and_then(|e| e.to_str()) != Some("json") { continue; }
        let bytes = match std::fs::read(&path) { Ok(b) => b, Err(_) => continue };
        let s = match parse_session(&bytes) { Ok(s) => s, Err(_) => continue };
        let alive = pid_alive(s.pid, &sys);
        let status = map_status(&s.status, alive);
        let mut st = AgentState {
            pid: s.pid, session_id: s.session_id.clone(), name: s.name.clone(),
            cwd: s.cwd.clone(), repo: repo_from_cwd(&s.cwd), branch: None,
            status, raw_status: s.status.clone(), started_at: s.started_at,
            status_updated_at: s.status_updated_at, model: None, context_pct: None, last_activity: None,
        };
        if enrich && alive {
            let e = enrich_from_path(&transcript_path(&s.cwd, &s.session_id));
            st.model = e.model; st.context_pct = e.context_pct; st.branch = e.branch;
        }
        out.push(st);
    }
    out.sort_by(|a, b| b.status.priority().cmp(&a.status.priority()).then(a.name.cmp(&b.name)));
    out
}
```

```rust
use std::sync::{Arc, Mutex};
use std::time::Duration;
use tauri::{AppHandle, Emitter, Manager};
use notify::{RecommendedWatcher, RecursiveMode, Watcher};
use crate::aggregate::{summarize, transitions};

pub type Shared = Arc<Mutex<Vec<AgentState>>>;

pub fn start_watching(app: AppHandle, shared: Shared) {
    std::thread::spawn(move || {
        let dir = sessions_dir();
        let _ = std::fs::create_dir_all(&dir);
        let (tx, rx) = std::sync::mpsc::channel();
        let mut watcher: RecommendedWatcher = match notify::recommended_watcher(move |res| { let _ = tx.send(res); }) {
            Ok(w) => w, Err(_) => return,
        };
        let _ = watcher.watch(&dir, RecursiveMode::NonRecursive);
        loop {
            let window_visible = app.get_webview_window("main").and_then(|w| w.is_visible().ok()).unwrap_or(false);
            let next = scan_once(&dir, window_visible);
            let prev = { shared.lock().unwrap().clone() };
            if next != prev {
                for t in transitions(&prev, &next) {
                    let _ = app.emit("agent-transition", &t);
                }
                let _ = app.emit("agents-updated", &next);
                let _ = app.emit("tray-summary", &summarize(&next));
                *shared.lock().unwrap() = next;
            }
            // drain events (non-blocking) then sleep the reconcile interval
            while rx.try_recv().is_ok() {}
            std::thread::sleep(Duration::from_millis(2000));
        }
    });
}
```

```rust
pub struct Settings { pub sound_enabled: bool, pub sound_on_idle: bool }
```

```rust
// notify.rs
use tauri::AppHandle;
use tauri_plugin_notification::NotificationExt;
use crate::aggregate::Transition;
use crate::model::AgentStatus;
use crate::settings::Settings;

pub fn notify_transition(app: &AppHandle, t: &Transition, settings: &Settings) {
    let body = match t.to {
        AgentStatus::Waiting => format!("{} is waiting on you", t.name),
        AgentStatus::Idle => format!("{} is idle, feed it", t.name),
        _ => return,
    };
    let _ = app.notification().builder().title("Homa").body(&body).show();

    let play = settings.sound_enabled
```

```rust
// probe.rs
use std::sync::Mutex;
use std::collections::HashSet;
static SEEN: Mutex<Option<HashSet<String>>> = Mutex::new(None);

pub fn record(raw: &str) {
    let raw = raw.trim().to_ascii_lowercase();
    if raw.is_empty() { return; }
    let mut g = SEEN.lock().unwrap();
    let set = g.get_or_insert_with(HashSet::new);
    if set.insert(raw.clone()) {
        let p = dirs::config_dir().unwrap_or_default().join("homa").join("observed-statuses.log");
        if let Some(d) = p.parent() { let _ = std::fs::create_dir_all(d); }
        use std::io::Write;
        if let Ok(mut f) = std::fs::OpenOptions::new().create(true).append(true).open(p) {
            let _ = writeln!(f, "{}", raw);
        }
    }
}
```
