Design Spec · Inspired by gavraz/recon

Homa

The Persian bird that never lands — a monitor for a flock of always-running agents.

A featherweight Windows tray app that watches your Claude Code agents and tells you, at a glance, which ones need you — quiet while they work, loud when one goes idle or blocks on you, even while you game.

2026-07-24 Stack · Tauri (Rust + React/Tailwind) Form · System tray + overlay Status · Approved, pending review

1Problem

Saeid runs several Claude Code agents at once, each in its own Windows Terminal tab. There is no single place to see which are working, which are blocked on him, and which have gone quiet. When he steps away to game, a finished or blocked agent can sit unnoticed for a long time.

recon solves this on Unix by sitting on tmux — enumerating sessions and scraping each pane's status bar. That substrate does not exist on Windows: no tmux, and Windows Terminal exposes no supported API to read tab or pane content. So Homa is not a port; it is a reimagining on a cleaner substrate.

2Goal

  • Read the live roster + status of every Claude Code session without touching the terminal.
  • Signal attention through a layered model that still works while a game runs.
  • Treat idle as an attention state (a finished agent awaiting its next task) — only actively working is calm.
  • Stay featherweight enough to run behind a fullscreen game without stealing meaningful RAM/CPU.

3Substrate — the key finding

Windows Claude Code already writes a per-session status file. No terminal scraping required:

~/.claude/sessions/<pid>.json

{
  "pid": 13732,
  "sessionId": "1fe8e5c7-20c9-40cf-80b2-4f1c1968088b",
  "cwd": "C:\\Users\\saeid\\Desktop\\Agent Simorgh",
  "name": "agent-simorgh-61",
  "status": "busy",
  "startedAt": 1784898651809,
  "statusUpdatedAt": 1784898664841,
  "version": "2.1.218"
}

This hands us the whole roster recon rebuilds from tmux — name, cwd (→ repo/branch), a live status, timestamps. The matching transcript ~/.claude/projects/<slug>/<sessionId>.jsonl adds model, context %, and last-activity when we want it.

Open item: the full set of status values must be enumerated empirically (only busy observed so far). The mapper must fail safe for any unrecognized value.

4Form factor & stack

Form

Tray app + summonable main window + optional always-on-top mini-pill overlay. Normally hidden; lives in the tray.

Why Tauri, not Electron

Uses Windows 11's built-in WebView2 → ~10 MB / low idle RAM. It must not compete with a running game; Electron's Chromium fails that test.

Why Tauri, not C#/.NET

The animated pixel-art tamagotchi is far faster to build in React/Tailwind. Rust handles only OS glue.

5Architecture

Rust core

ComponentResponsibility
Pollernotify file-watcher on the sessions dir for instant reaction + a ~2 s reconcile tick for in-place rewrites and process death.
Liveness checkerCross-check each file's pid against running processes so a crashed session doesn't linger as fake "idle."
Status mapperNormalize raw status into the 3-state model; unknown values fail toward attention.
Enricher (lazy)Only while the window is open, read transcript tails for model / context % / last-activity. Skipped when hidden → near-idle during gaming.
Tray managerDrive icon variant + badge and tray menu (show/hide, quit, per-session list).
NotifierNative Windows toasts on transitions. Auto-suppressed in fullscreen games — intended.
Overlay controllerShow/hide + position the mini-pill overlay window.

React / Tailwind UI

  • Roster view — agents grouped by repo (from cwd): name, repo/branch, state, context %, last activity. (recon's table analog.)
  • Tamagotchi view — each agent an animated pixel creature reflecting its state; toggle with roster.
  • Mini-pill overlay — small frameless always-on-top window (§7).

6Data flow

~/.claude/sessions/*.json ──(notify + 2s reconcile)──▶ Poller
        │  pid liveness (sysinfo)                          │
        │  transcript tail (lazy, window-open only)        ▼
        │                                          Status mapper ──▶ AgentState[]
        └──▶ AgentState[] fans out to:
               (a) Tray icon variant + badge
               (b) Toast on state transition
               (c) Tauri event ──▶ React: roster / tamagotchi / overlay

7State & signaling model

Only working is calm. Idle and waiting are both attention states, kept visually distinct.

StateMeaningTrayToastOverlay
WorkingActively doing workCalm blue/greennohidden
IdleFinished, unused — feed itAmber, pulsing + count"…is idle"shown
WaitingBlocked on your inputRed + count"…is waiting on you"shown
Endedpid dead / goneGrey, then droppednohidden
  • Tray icon shows the highest-priority state: waiting > idle > working. Accurate even in-game — a taskbar glance suffices.
  • Toast on transitions, debounced. Suppressed in fullscreen games (intended).
  • Sound — optional, off by default; configurable chime on waiting (optionally idle). Pierces games.
  • Mini-pill overlay — draggable, corner-parkable, position persisted. Auto-shows only on attention, hides when all calm. Visible over borderless/windowed-fullscreen.
Honest limit: exclusive-fullscreen games suppress every overlay — nothing on Windows defeats that. The tray glance and optional sound are the fallbacks there.

8Error handling

ConditionBehavior
Mid-write / partial JSONRetry/skip; keep last good parse.
Dead pid, file presentMark Ended, grey out, drop after grace.
Sessions dir missing / emptyNeutral tray + empty state.
Unknown statusTreat as attention (don't hide).
Transcript missing / hugeCap tail read; degrade to "no context info."
Enricher errorRoster still renders from the session file alone.

9Testing

  • Rust unit tests — parser, status mapper, liveness against fixtures (well-formed, malformed, dead-pid, unknown-status).
  • Replay / fixture mode — a fake sessions dir with scripted files to simulate working → waiting → idle → ended deterministically; drives tray, toast, and overlay.
  • Frontend component tests — roster + tamagotchi per state; overlay show/hide.
  • Manual smoke — real claude sessions end-to-end (type-check passing ≠ feature working).

10Scope

In — v1

Tray app + main window · substrate poller (watch + reconcile + liveness + lazy enrichment) · 3-state model + Ended · tray icon variants + badges · toasts + optional sound · roster + tamagotchi views · mini-pill overlay · autostart + start-minimized.

Out — later

recon's session command suite (launch/resume/park) · "jump to that WT tab" (no supported API; best-effort window-foreground is a fast-follow) · history/usage graphs · multi-machine aggregation.
